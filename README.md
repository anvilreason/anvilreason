## 怎么直接用这里的 Skill？

1. 点进对应 Skill 仓库，打开根目录的 `SKILL.md`（或点 `Raw` 全选复制）。
2. 直接粘贴给你的 **ChatCut / Claude Code / Codex / Cursor / 任意 AI Agent** 即可生效。
3. 所有 Skill 都会随真实一线业务持续更新，每次改动都会记录在对应仓库的 `CHANGELOG.md` 中。
